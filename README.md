# Infinite Asure

The official site for **Infinite Asure**, an open-world pirate game in development, built in Unity.

> Caribbean, 1717. Betrayed, left for dead, and sworn to hunt the man who did it, across a sea that has no end.

## What's on the site

- A live, rendered dusk sea with a galleon riding the swell (WebGL)
- An original orchestral pirate theme, plus wind and waves generated live in the browser
- The story, the crew, a clickable sea chart of the Isle and in-engine screenshots
